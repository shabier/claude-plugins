# arcade

Five small games in the side pane. `/arcade` opens the list.

| Key | Game | Controls |
|---|---|---|
| 1 | Rail Runner | `a` `d` lanes, `w` jump, `s` roll |
| 2 | Road Hopper | `w` hop, `a` `d` sideways, `s` back |
| 3 | Block Drop | `a` `d` move, `w` turn, `s` down, `x` drop |
| 4 | Flap | `w` flap |
| 5 | 2048 | `w` `a` `s` `d` slide, `r` new board |

`q` back to the list, `p` pause. Keys work after a click on the pane or `ctrl+x tab`. A run pauses when the pane loses them.

## Commands

| Command | Does |
|---|---|
| `/arcade` | open or close |
| `/arcade <game>` | start one: `rail`, `hopper`, `blocks`, `flap`, `2048` |
| `/arcade autostart on\|off` | open at session start. Off by default |

Best scores stick across sessions.
